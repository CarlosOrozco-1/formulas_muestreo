📐 Fórmulas Utilizadas
n = Z² · p · (1 − p) E²

Se usa cuando la población es muy grande o desconocida (N ≥ 100,000). La muestra depende únicamente del nivel de confianza, la varianza esperada y la precisión deseada — no del tamaño total de la población.

n— Tamaño de muestra calculado
Z— Valor crítico (nivel de confianza)
p— Proporción esperada del evento
1-p— Complemento (varianza máxima con p=0.5)
E— Margen de error aceptable
n₀ = Z² · p · (1 − p) E²  →  nf = n₀ · N N + n₀ − 1

Primero se calcula la muestra para universo infinito (n₀), luego se aplica el Factor de Corrección para Población Finita, que reduce el tamaño de muestra al conocer el total de elementos N. Esto es correcto cuando N < 100,000.

n₀— Muestra para universo infinito
N— Tamaño total de la población
nf— Muestra ajustada (resultado final)
N+n₀−1— Denominador de ajuste poblacional
f(x) = 1 σ√(2π) · e−½((x−μ)/σ)²

La distribución normal estándar (μ=0, σ=1) describe la probabilidad de cada valor Z. El área bajo la curva entre −Z y +Z representa el nivel de confianza: la probabilidad de que el verdadero parámetro caiga dentro del intervalo estimado.

μ— Media (0 en distribución estándar)
σ— Desviación estándar (1 en dist. estándar)
e— Número de Euler ≈ 2.71828
π— Pi ≈ 3.14159
x— Valor (desviación estándar a evaluar)
f(x)— Densidad de probabilidad en x
📈 Campana de Gauss — Distribución Normal Estándar
🔵 Área de Confianza (azul) Zona entre −Z y +Z que representa el 95% de los datos. Dentro de esta región caerán la mayoría de las respuestas reales de tu población.
🔴 Cola de Rechazo (rojo) Zona fuera de ±Z. Representa el 5% de margen de error (α = error de tipo I). Probabilidad de rechazar resultados verdaderos.
📍 Valor Z = ±1.96 Puntos críticos que dividen la campana. El área entre estos límites define tu nivel de confianza.
📐 Teorema del Límite Central Con n ≥ 30, la distribución de medias muestrales tiende a la normal, lo que valida el uso de esta fórmula independientemente de la distribución original.
